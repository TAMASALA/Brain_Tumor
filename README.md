# ✨ Project Overview

**Brain Tumor Classification using CNN** is a Computer Vision project that applies Deep Learning techniques to automatically classify brain MRI scans into one of four clinically relevant categories.

The system performs image preprocessing, normalization, augmentation, and feature extraction using a custom CNN architecture before generating predictions through a trained classification model.

The trained model achieves approximately **95% validation accuracy**, demonstrating the effectiveness of CNNs for medical image classification tasks.

> ⚠️ **Disclaimer:** This project is intended for educational and research purposes. Predictions generated by the model should not be considered a medical diagnosis and must always be reviewed by qualified healthcare professionals.

# 🧩 Dataset

The model is trained on Brain MRI images containing four categories.

### Classification Labels

- 🧠 Glioma Tumor
- 🧠 Meningioma Tumor
- 🧠 Pituitary Tumor
- ✅ No Tumor

### Dataset Statistics

- Approximately **2,500 MRI Images**
- Multi-class image classification
- Balanced preprocessing pipeline

---

# 🔬 Image Processing Pipeline

Before training, every MRI image undergoes multiple preprocessing stages.

### Image Preparation

- Image Cleaning
- Image Resizing
- Pixel Normalization
- Data Augmentation
- Dataset Splitting

These preprocessing steps improve model generalization and reduce overfitting.

---

# 🧠 CNN Architecture

The custom Convolutional Neural Network consists of:

- Convolution Layers
- ReLU Activation
- Max Pooling
- Batch Normalization
- Global Average Pooling
- Fully Connected Dense Layers
- Softmax Output Layer

This architecture learns hierarchical image features from low-level textures to high-level tumor representations.
